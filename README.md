# 廢棄物代碼聯單檢查

事業廢棄物的代碼判定與遞送聯單時限檢查，單一網頁，不需安裝、不連線官方系統、不儲存輸入資料。

網址：https://p19691221-web.github.io/waste-check/

## 功能

- **代碼判定**：依《有害事業廢棄物認定標準》的順序，先看列表（製程有害、混合五金、生物醫療），再依 pH、閃火點、多氯聯苯、戴奧辛、TCLP 溶出結果比對有害特性門檻，都不符才建議一般事業廢棄物（D 類）代碼；送再利用時另給 R 類代碼。缺少數據時會列出還無法排除的有害特性。
- **聯單檢查**：依 114 年 1 月 3 日修正的網路申報公告檢查時限（離廠後 2 日內送達、收受後 1 日內申報、事業 4 日內確認、完成後 1 日內申報、清運後 35 日內查詢），並比對清除者與處理者的許可代碼、流向與代碼類別、三個重量的差異。
- **代碼查詢**：常見代碼約 90 個，可依名稱或類別搜尋。

## 限制

- **僅供申報前自我檢查。** 正式代碼以環境部「事業廢棄物申報及管理資訊系統」與核准的清理計畫書為準；有害與否以檢測結果與主管機關認定為準。
- 代碼表整理自業者公開的許可代碼清單，非官方完整版。兩份清單名稱一致者標「兩來源」，其餘標「單一來源」。
- B 類（毒性化學物質）只提示類別，不給代碼。
- 時限以 24 小時為 1 日計算，未計入假日順延與離島例外。
